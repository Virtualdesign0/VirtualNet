# VirtualNet

Roblox networking tool.

VirtualNet is a Roblox networking module made for typed packets, schemas, batching, and cleaner remote organization in Roblox projects.

**Why use this?**  
It gives you a simple way to define packets, validate data, batch traffic, and keep networking code organized without filling your game with random RemoteEvents.

Full documents are here: [Documents](https://virtualdesign0.github.io/VirtualNet/)

You can also find benchmark results there, including comparisons against ByteNet and Blink.

Latest release: [Releases](https://github.com/Virtualdesign0/VirtualNet/releases/latest)
